# So bekommst du das Profil aus dem Screenshot

Dein GitHub-Benutzername ist **LilProgram**. GitHub zeigt ein Profil-README nur an,
wenn es in einem öffentlichen Repository liegt, das **exakt so heißt wie dein
Benutzername** — also `LilProgram/LilProgram`. Ein Repo namens `Ismail` wird auf
deiner Profilseite **nicht** angezeigt.

## 1. Repo umbenennen (wichtigster Schritt)

1. Öffne dein Repo `Ismail` → **Settings** → Abschnitt **General**.
2. Bei **Repository name** den Namen von `Ismail` in `LilProgram` ändern → **Rename**.
3. Das Repo muss **Public** sein (ist es schon ✓).

GitHub zeigt dir danach den Hinweis *"LilProgram is a ✨special✨ repository"* —
dann ist alles richtig.

> Alternative: Wenn du lieber `Ismail` behalten willst, müsstest du stattdessen
> deinen **Benutzernamen** in `Ismail` ändern (Settings → Account → Change username).
> Das ändert aber alle deine URLs — die Umbenennung des Repos ist der einfachere Weg.

## 2. README einfügen

Lege im Repo `LilProgram/LilProgram` eine Datei **`README.md`** an (im Root, exakt
dieser Name) und kopiere den Inhalt aus der Datei [`README.md`](README.md) in
diesem Ordner hinein. Der Inhalt erscheint dann oben auf deiner Profilseite —
wie das weiße Kästchen ("detailed personal readme") im Screenshot.

## 3. Die übrigen Elemente aus dem Screenshot

- **Profilbild** (gelber Kreis): github.com → oben rechts auf deinen Avatar →
  **Settings** → **Profile** → **Profile picture** hochladen.
- **Bio, Ort, Website, Social Links**: ebenfalls unter Settings → Profile.
  Dort kannst du z. B. LinkedIn, ercikdi.com usw. eintragen (erscheint links
  unter deinem Namen).
- **Pinned repositories** (roter Kasten): Auf deiner Profilseite →
  **Customize your pins** → bis zu 6 öffentliche Repos anpinnen. Dafür brauchst
  du weitere öffentliche Repos — pushe z. B. deine Projekte (Citizenship Trainer,
  Ladybugs, Tokenizer, Portfolio) als eigene Repos mit kurzer Beschreibung und Topics.
- **Contribution-Graph** (grüner Kasten): füllt sich automatisch mit deinen
  Commits. Tipp: Unter Settings → Profile → **Private contributions** aktivieren,
  dann zählen auch private Commits (anonym) mit.
- **Achievements** (pinker Kasten): vergibt GitHub automatisch — z. B.
  *Pull Shark* (gemergte Pull Requests), *YOLO* (PR ohne Review gemergt),
  *Quickdraw* (Issue/PR in unter 5 Min. geschlossen). Die kommen mit der Zeit
  von selbst.
- **Achievements/Highlights wie "Developer Program Member"**: unter
  https://docs.github.com/developers kostenlos beitreten.

## 4. Fertig

Sobald Repo umbenannt + README drin ist, sieht deine Profilseite aus wie im
Screenshot: README oben, darunter Pins, links Bild/Bio/Links, unten der
Contribution-Graph.
